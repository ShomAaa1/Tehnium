Что такое Grid?

CSS Grid — мощная двухмерная система раскладки, которая позволяет управлять рядами и колонками одновременно. В этом примере показаны: grid-template-areas, auto-fit + minmax для адаптивной сетки галереи, и выравнивание элементов.
